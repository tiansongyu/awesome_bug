# Turtle artwork provenance

`turtle_parts_atlas.png` was created specifically for this repository on
2026-07-31 with OpenAI's built-in image generation tool. The generation used
only the following text specification and no reference image:

> An adorable juvenile land tortoise rendered as a polished semi-realistic 3D
> game character from an exact orthographic top-down angle, facing upward,
> with a honey-brown shell, olive-sage skin, friendly eyes, four short legs and
> a small tail, on a flat solid magenta chroma-key background.

The generated master was chroma-keyed and separated into the shell, head, four
legs and tail. The resulting atlas and `packaging/turtle.ico` are distributed
under the repository's MIT license to the extent copyright applies.
