# Windows 单蟑螂交互行为设计

## 范围

本轮只扩展 Windows 单蟑螂程序 `cockroach_overlay.exe`。20 只群体版本和
Linux 交互暂不启用新功能，但共享运动、碰撞和渲染代码必须继续通过构建与
回归测试。

## 分层

- `main.cpp`：采集 Windows 全局鼠标、快捷键和交互命令。
- `Cockroach`：统一行为状态机、目标选择、运动、身体命中测试和生命周期。
- `cockroach_parts.cpp`：根据行为输出六足、双触须和死亡姿态。
- `OverlayWindow`：只负责透明置顶窗口和逐帧显示，不保存行为。

所有状态切换必须经过 `Cockroach::transitionTo()`。图标避障和卡住恢复是
独立于行为状态的运动约束，不能绕过状态机直接改变状态。

## 状态及优先级

状态优先级从高到低：

1. `Dead`：拍死后冻结 10 秒。
2. `Startled` / `Flee`：鼠标快速接近后的停顿和爆发逃跑。
3. `SeekFood` / `Feeding`：接近并食用用户投放的诱饵。
4. `SeekCorner` / `Lurk` / `Groom`：前往角落、潜伏、清洁身体。
5. `Wander` / `Creep` / `Pause`：原有随机运动。

图标重叠脱离和卡住恢复可以临时覆盖移动方向，但不改变死亡或主动静止状态。

## Windows 操作

- `Ctrl+Alt+Q`：退出。
- `Ctrl+Alt+S`：进入或退出拖鞋捕杀模式。
- 捕杀模式下左键：播放拖鞋拍击；身体命中后进入死亡状态。
- `Ctrl+Alt+F`：在当前鼠标位置投放或移动食物诱饵。

拖鞋模式必须是显式开启的临时模式，退出时恢复普通指针行为。食物使用快捷键
投放，避免普通右键操作同时触发桌面菜单。

## 验证

- 使用固定随机种子验证状态转换和轨迹可重复。
- 每个新状态都具有确定性的纯 C++ 测试。
- 保留图标碰撞、边缘脱困、速度变化和肢体动画回归。
- 最终执行 Linux Release/ASan 测试、MinGW Windows x64 交叉编译、
  Wine 测试以及 Windows 11 虚拟机交互验证。
