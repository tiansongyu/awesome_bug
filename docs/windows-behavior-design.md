# Windows 单蟑螂交互行为设计

## 范围

本轮只扩展 Windows 单蟑螂程序 `cockroach_overlay.exe`。20 只群体版本和
Linux 交互暂不启用新功能，但共享运动、碰撞和渲染代码必须继续通过构建与
回归测试。

## 分层

- `main.cpp`：采集 Windows 全局鼠标、快捷键和交互命令。
- `Cockroach`：统一行为状态机、目标选择和运动。
- `cockroach_parts.cpp`：根据行为输出六足和双触须姿态。
- `OverlayWindow`：只负责透明置顶窗口和逐帧显示，不保存行为。

所有状态切换必须经过 `Cockroach::transitionTo()`。图标避障和卡住恢复是
独立于行为状态的运动约束，不能绕过状态机直接改变状态。

Windows 可见窗口的 Z-order 固定为：

1. 蟑螂覆盖窗口。
2. 食物覆盖窗口。
3. 普通桌面及应用窗口。

食物每帧显示后都重新放到蟑螂窗口正下方，避免两个独立的置顶窗口因显示、
切换应用或重新投放而交换顺序。

## 状态及优先级

状态优先级从高到低：

1. `Startled` / `Flee`：鼠标快速接近后的停顿和爆发逃跑。
2. `SeekFood` / `Feeding`：接近并食用用户投放的诱饵。
3. `SeekCorner` / `Lurk` / `Groom`：前往角落、潜伏、清洁身体。
4. `Wander` / `Creep` / `Pause`：原有随机运动。

图标重叠脱离和卡住恢复可以临时覆盖移动方向，但不改变主动行为状态。

## Windows 操作

- `Ctrl+Alt+Q`：退出。
- `Ctrl+Alt+F`：在当前鼠标位置投放或移动食物诱饵。

食物使用快捷键投放，避免普通鼠标操作同时触发桌面菜单。程序不会替换系统
指针或拦截桌面点击。

两个 Windows 可执行文件使用同一个含 16、24、32、48、64、128 和
256 像素图像的蟑螂程序图标。

## 验证

- 使用固定随机种子验证状态转换和轨迹可重复。
- 每个新状态都具有确定性的纯 C++ 测试。
- 保留图标碰撞、边缘脱困、速度变化和肢体动画回归。
- 最终执行 Linux Release/ASan 测试、MinGW Windows x64 交叉编译、
  Wine 测试以及 Windows 11 虚拟机交互验证。
