# Cockroach component sprites

`cockroach_parts_atlas.png` 是程序使用的 1536×1024 写实组件图。身体、六条腿和两根触须分别占用互不重叠的区域，可由 SDL2 独立旋转与移动。`cockroach_parts/` 同时保存了九张独立 PNG，便于逐个检查和替换。

## 来源

- 编辑基础：用户在当前任务中指定的高细节正俯视背部图
- 组件生成源：`cockroach_parts_sheet_source.png`
- 分离前透明组件图：`cockroach_parts_sheet.png`
- 本项目不对用户提供素材的外部来源或授权作额外推断

## 本项目所做修改

- 使用内置图像生成能力制作一张精确的九组件图，包含一具无附肢身体、恰好六条分节带刺的腿和两根触须。
- 使用纯绿色背景生成，再移除背景和绿色溢色。
- 按连通区域自动识别身体、左右前/中/后腿及左右触须，导出九张独立 PNG。
- 将九个组件重新排入互不重叠的运行时 atlas，避免独立绘制时采样到相邻器官。
- 最终 alpha 通道为二值：背景为 `0`，所有可见蟑螂像素为 `255`。

因此，运行时透明的只有蟑螂周围的桌面覆盖区域；蟑螂主体没有半透明像素。
