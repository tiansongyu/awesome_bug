# Cockroach sprite

`cockroach_full.png` 是以用户指定的高细节背部素材为基础补全的 1024×1535 写实渲染图。画面保持严格正俯视，包含完整背甲、翅膀、腹节、六足、足刺、复眼、口器和双触角。

## 来源

- 编辑基础：`build-asan/assets/cockroach_body.png`
- 基础素材尺寸：1024×1536
- 基础素材由用户在当前任务中指定
- 本项目不对用户提供素材的外部来源或授权作额外推断

## 本项目所做修改

- 使用内置图像编辑能力，在原背部主体周围补齐恰好六条分节带刺的腿和两根触角。
- 添加正俯视角度下可见的复眼与小型口器，并保持头部朝上。
- 使用纯绿色背景生成，再通过本地图像处理移除背景和绿色溢色。
- 将最终 alpha 通道硬化为二值：背景为 `0`，所有可见蟑螂像素为 `255`。

因此，运行时透明的只有蟑螂周围的桌面覆盖区域；蟑螂主体没有半透明像素。
